Problem Definition:
You want to predict a customer’s future monthly data usage (in GB) or call minutes based on their historical usage data. This would help telecom companies with resource planning (e.g., bandwidth allocation, predicting demand for network infrastructure) or creating personalized marketing strategies.

Dataset: You have monthly historical data for each customer, including:
Customer ID: Unique identifier for each customer.
Month: The time of the data (e.g., year-month, 2023-01).
Total Call Minutes: The total call time for the month.
Data Usage (GB): The total amount of data consumed in a month.
Customer Type: E.g., Prepaid or Postpaid.
